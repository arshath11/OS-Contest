# Printing-Service-FCFS

A simple web-based **Printing Service Scheduler** that demonstrates the **First Come First Serve (FCFS)** scheduling algorithm.

## Features

- Add print jobs with Job ID, User Name, and Printing Time
- Process jobs in FCFS order
- Display the print queue
- Calculate completion time
- Display an FCFS Gantt chart
- Show completed jobs and total printing time
- Activity history
- Reset the scheduler

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Add print jobs.
4. Click **Process Next Job** to execute them in FCFS order.

## FCFS Algorithm

FCFS processes jobs according to their arrival order.

Example:

`J1 → J2 → J3 → J4`

If the printing times are 5, 3, 4, and 2 minutes, the completion times are:

- J1 = 5
- J2 = 8
- J3 = 12
- J4 = 14
